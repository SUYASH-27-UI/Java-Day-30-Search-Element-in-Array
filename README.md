# Java Day 30 - Search an Element in an Array

This Java program searches for a specific number in an array and displays whether the number is found.

## Example

Array: `10, 20, 30, 40, 50`

Search number: `30`

Output:
```text
Number found!
```

## Concepts Used

- Arrays
- `for` loop
- `if-else` statement
- Comparison operator `==`
- Boolean variable
- `break` statement

## How It Works

The program checks each array element against the search number. If the number matches, the `found` variable becomes `true` and the loop stops. Finally, the program displays whether the number was found.
